# 单条路线交付验收：流程与排班

依据《川行无人车智驾验收测试标准》（下称 W1）整理 · v6.1 · 2026-10-10 · 单条路线来回 > 20 次

## 一、验收流程

门式流程：**上一道门通过后才能进入下一道；任一道不通过，就地返修后重验，不进入下一阶段。**前三道门的放行判据取自《川行》原文，不由本标准自定。

![验收流程图](@./route_flow_fig.png)

文字版：输入单条路线（起点 — 途经点 — 终点）→ G1 HIL 逻辑测试 →（通过？）→ G2 SIL 地图验证 →（通过？）→ G3 封闭场地验收 →（通过？）→ G4 排班采集 → G5 评测器评测地图 →（全部闭环？）→ 移交运营。任一判定为否：就地返修后重验；终判未闭环：返工失败项复验，不重跑全程。

### 各阶段做什么、按什么放行

| 阶段 | 做什么 | 放行判据 | 出处 |
|---|---|---|---|
| G1 HIL 逻辑测试 | 真实域控上台架，实时仿真注入场景；功能逻辑与状态机、MRM、失效接管、交通合规、上下电压力、故障降级、标定、远遥 | 冒烟执行率 / 通过率 **100%**；**无 P0 安全缺陷**、P1 清零；**基础状态逻辑问题 0**；远遥控制权切换类用例 **0 失败** | W1 |
| G2 SIL 地图验证 | 规控跑服务器，虚拟地图闭环；区域地图遍历、途经点、路径重规划、定位异常 | **区域地图遍历率 ≥ 98%**、关键节点 / 路线点 **100% 覆盖**；路径重规划成功率、定位异常安全降级触发率 **100%**；输出《区域地图验收测试报告》 | W1 |
| G3 封闭场地验收 | 整车在封闭测试场，环境可控、场景可摆设；19 项场地试验 + 法规 / 路权用例 | 安全策略与远程接管稳定，**无 P0 / P1 阻塞**；法规 / 路权用例**执行率 100%** | W1 / GB/T 41798-2022 |
| G4 排班采集 | 按 §2.2 排班表出车，21 个来回（空载 / 满载覆盖）；**每个来回既是功能测试的执行遍，也全程录制 ROS bag** | 来回 > 20 次且**累计实车里程 ≥ 200 km（含空载与满载）**；关键场景反复验证；**每遍均为有效遍**；干预 / 接管 / MRM 事件 **100% 记录并归因** | 本文件 §2 / W1 · 验收体系 1.4 |
| G5 评测地图 | 评测器离线全量比对（感知静态要素 ↔ 宽凳真值）；差异逐条归因；一致项抽检复核 | **差异 100% 归因闭环**；一致项抽检**未发现评测器漏检** | 本文件 §2.4 |

## 二、排班

### 2.1 为什么这么排

排班不是凑时间，是把上位标准**写死的配额**落到具体时段。总量、分布、下限都是《川行》明文，排班人无权自定。

| 序 | 约束 | 上位标准要求 | 出处 |
|---|---|---|---|
| ① | 总量 | 单条路线来回 **> 20 次** | W1 · 2.1 |
| ② | 高峰 | 早 / 午 / 晚高峰**各至少 2 次** | W1 · 2.2.1 |
| ③ | 时段比例 | 其余时段按 **3 : 3 : 4**；**上、下午各 ≥ 1 次**，**夜间 ≥ 2 次** | W1 · 2.2.1 |
| ④ | 固定运营 | 客户有固定发车时间时，以客户发车时间为主，**不低于 50 km 或 3 次** | W1 · 2.2.2 |
| ⑤ | 时段划分 | 昼夜按当地日出日落划分；同一自然日累计覆盖 **td1 / td2 / tn1 / tn2** | GB/T 44719-2024 · 4.4 |
| ⑥ | 里程与载荷 | 单条路线**实车测试不少于 200 km，含空载与满载**；关键场景需反复验证 | W1 · 验收体系 1.4 |

> **从约束到「21 个来回、各时段几个」的推导（约束是原文，分配是算出来的，可复核）：**
> ① 高峰：早 / 午 / 晚各 ≥ 2 次 —— 早、晚通勤流更强各上浮 1，即早 3 / 午 2 / 晚 3，共 8 个；
> ② 其余时段按 3 : 3 : 4 分给上午 / 下午 / 夜间：剩余 21 − 8 = 13 个，13 × 3/10 ≈ 4（上午）、13 × 3/10 ≈ 4（下午）、13 × 4/10 ≈ 5（夜间）；
> ③ 校验：3 + 4 + 2 + 4 + 3 + 5 = 21 ✓；高峰各 ≥ 2 ✓；上下午各 ≥ 1 ✓；夜间 ≥ 2 ✓；其余 4 : 4 : 5 ≈ 3 : 3 : 4 ✓；
> ④ **短路线追加规则**：若 21 × 2 × 单程里程 \< 200 km（即单程 \< 4.8 km），来回数上调至累计里程 ≥ 200 km 为止（约束 ⑥）。

### 2.2 排班总表（无固定运营时间 · 默认配置）

取 **21 个来回**（满足 > 20 次）分摊：三个高峰各 ≥ 2，夜间 ≥ 2，其余按 3 : 3 : 4 分给上午 / 下午 / 夜间。

| 序 | 时段 | 时间窗口 | 来回 | 单程遍 | 这么排的依据 | 本班次测试内容 | 对应验收指标 |
|---|---|---|---|---|---|---|---|
| 1 | 早高峰 | 07:00–09:00 | 3 | 6 | 高峰各 ≥ 2 次，取 3 覆盖通勤高峰段 | 拥堵跟车与起步、行人 / 非机动车混入、路口多相位信号 | DDT 合规（REQ-R-008） |
| 2 | 上午平峰 | 09:30–11:30 | 4 | 8 | 3 : 3 : 4 中上午份额；兼满足「上午 ≥ 1 次」 | **基准采集**：光照与交通最稳，作为评测器比对主数据集 | 地图静态数据全项（§2.4） |
| 3 | 午高峰 | 11:30–13:30 | 2 | 4 | 高峰各 ≥ 2 次（取下限） | 路口通行、车辆停走、短时变密车流 | DDT 合规 + 后援（REQ-R-008 / 010） |
| 4 | 下午平峰 | 14:00–16:30 | 4 | 8 | 3 : 3 : 4 中下午份额；兼满足「下午 ≥ 1 次」 | 与序 2 作**同向重复性校验**（版本不变、两次独立采集） | 可靠性（§2.4） |
| 5 | 晚高峰 | 17:00–19:30 | 3 | 6 | 高峰各 ≥ 2 次；跨越日落，兼顾白天与夜间低照 | 逆光、大型车遮挡、拥堵跟车、路口饱和流 | DDT 合规 + 地图（REQ-R-008） |
| 6 | 夜间 | 19:30–23:00 | 5 | 10 | 夜间 ≥ 2 次，取 5 承接 3 : 3 : 4 中最大份额 | 低照下要素感知与灯光依赖、隧道口、无路灯段 | 夜间地图与 DDT（§2.4） |

合计：**21 个来回 / 42 个单程遍**——满足总量 > 20、高峰各 ≥ 2、夜间 ≥ 2、上下午各 ≥ 1、其余 3 : 3 : 4；td1 / td2 / tn1 / tn2 时段组合全覆盖。

执行顺序：序 1 + 2 同日连做（早 → 上午）；序 3 + 4 同日连做（午 → 下午）；序 5 + 6 同日连做（晚 → 夜间）。每个来回**先去程后返程，同一辆车、同一批人，中途不换车**。

载荷与专项（落在来回维度，不额外占时段）：① 空载 / 满载交替安排（如奇数来回空载、偶数来回满载），保证 200 km 内两种工况均覆盖；② AEB 误触发观察每遍进行；③ 端点、复杂路口、施工段等**关键场景须在多个时段反复出现并验证结论一致**；④ 泛化场景（cut-in、异形车、临时障碍等）随真实交通流自然出现，逐次记录归因。

### 2.3 每个班次做什么测试内容

#### 车端采集（每遍）

| 类别 | 要求 | 出处 |
|---|---|---|
| ROS bag | 全程录制：感知静态要素（停止线 / 标线 / 车道 / 限速）、定位与组合导航、感知结果、时间戳同步 | W1 · 数据落盘 |
| 运动状态 | 采样与存储 ≥ 50 Hz；速度精度 ≤ 0.1 km/h、位置 ≤ 0.1 m、加速度 ≤ 0.1 m/s² | GB/T 44719-2024 |
| 视频 | ≥ 1920×1080、帧率 ≥ 30 f/s | GB/T 44719-2024 |
| 事件记录 | 干预、接管、介入请求、MRM 事件**逐次记录时间戳并归因，100% 记录** | GB/T 44719-2024 / W1 |
| 端点操作 | 起点、终点、每个途经点各停留 10 min 静态确认并记录 | 本标准 |

#### 功能测试（随车 / 远程，每个来回都执行）

| 项 | 验证什么 | 验收指标 | 出处 |
|---|---|---|---|
| 端点通过性（关键项） | 起点、终点、**全部途经点**：停靠精度、进出通道、掉头 / 上下客区、与接驳点衔接 | 逐个全部合格，**零缺陷** | 本标准 / REQ-F-017 |
| DDT 执行合规 | 不骑轧车道分界线及边缘线、不越停止线、不超速、不违规占用应急车道、按优先通行权通过路口 | 全过程无违规 | REQ-R-008 |
| DDT 综合表现 | 适应他车行驶状态；除保持安全距离与换道外稳定于车道内；不无故紧急制动或转向 | 全过程无异常 | REQ-R-009 |
| DDT 后援 | 计划事件提前识别响应；介入请求持续发出且期间持续执行 DDT；MRM 期间持续执行 DDT、允许干预并有退出提示 | 事件 100% 记录并归因 | REQ-R-010 / 011 |
| 状态提示 | 就绪 / 激活有目视可见光学提示；转换、失效、介入请求、MRM 提示明显且可区分 | 全过程可辨 | REQ-R-012 |
| 无责任事故 | 无承担责任的交通事故、无非策略性干预 | 0 次 | REQ-R-007 |
| AEB 误触发 | 全程观察 AEB 有无误触发（无真实目标下的自动制动） | 0 次 | W1 · 验收体系 1.4 |
| MRC 最小风险 | 按计划注入严重故障（远遥配合）：安全靠边停车、双闪与语音警示、故障信息自动上传远控前台；碰撞后弹性波介入刹停并上报 | 全部动作按序完成 | W1 · 验收体系 1.3 |
| 关键场景反复验证 | 端点、复杂路口、施工段等关键场景在多个时段重复出现 | 多次验证结论一致 | W1 · 验收体系 1.4 |
| 云-车-远遥协同 | 远控接管、任务下发、链路视频等全链协同在真实道路下工作 | 功能正常，0 失败 | W1 · 测试模块架构 |

#### 离线评测（评测器）

把每一遍采回的 ROS bag 交给评测器**离线回放**：把**感知到的静态要素**与**宽凳高精真值**逐项空间匹配、逐项比对属性（STOPLINE / DIVIDER / LANE / ROAD_LINK）——**全量比对，不抽样**。输出分两路：

- **差异项** —— 逐条人工校核，判真差异或误检。真差异按三种去向处置，**没有「放过」**：地图错 → 修图并复验（阻断项）；感知错 → 转问题单跟踪闭环；误检 → 剔除并记录（评测器规则优化线索）。
- **一致项** —— 从评测器判为「一致」的要素中按里程分层抽样复核。这一步补的是评测器的**漏报**：只校核差异项只能发现误报，发现不了漏报；**若抽检发现漏检，评测器结论不可采信，转全量人工复核**。抽检不产生任何容忍额度。

#### 有效遍的条件

每一遍须同时满足下列条件，才计为**有效遍**；否则该遍作废、就地补采：

- 全程按规划路径行驶，无路段绕行或跳过
- 无安全接管、无非策略性干预
- ROS bag 完整（静态要素、定位 / 组合导航、时间同步）
- 定位全程有效，无丢失或大幅跳变
- 起终点及全部途经点按规范停留并完成记录

### 2.4 验收指标

#### 地图静态数据（G5 判据）

地图侧采用**缺陷闭环制，不设容忍额度**——评测器全量比对已把差异穷举出来，每条都是有效发现，必须归因闭环。

| 判据项 | 判据（阈值） | 出处 |
|---|---|---|
| 平面位置绝对精度 | ≤ 1.0 m | 自然资源部 · 高精地图数据规范 |
| 平面位置相对精度 | ≤ 0.2 m / 100 m | 中国测绘学会 · 高精地图产品规格 |
| 停止线位置与灯控属性 | 全部与真值一致，差异逐条闭环 | 本标准 |
| 标线线型、颜色一致率 | 100%（全量比对，无容忍额度） | 本标准 |
| 车道数、限速一致率 | 100%（全量比对，无容忍额度） | 本标准 |
| 差异闭环率 | 100% 归因处置完毕 | 本标准 |
| 评测器漏检验证 | 一致项抽检未发现漏检 | 本标准 |

#### 通过标准（可移交运营）

> **单条路线验收通过 ＝ 同时满足下列六项：**
> ① **前置门全部放行**：G1 / G2 / G3 的放行判据均已满足并取得对应报告；
> ② **采集完成**：完成 **≥ 21 个来回**（> 20 次）且**累计实车里程 ≥ 200 km（含空载与满载）**；td1 / td2 / tn1 / tn2 时段组合覆盖，每遍均为有效遍；
> ③ **端点与途经点**：起点、终点及全部途经点逐个确认合格，零缺陷；
> ④ **道路表现**：无责任事故、无非策略性干预、无不合规（越停止线 / 超速 / 骑轧车道线 / 违规占道）、AEB 无误触发；关键场景反复验证结论一致；事件 100% 记录并归因；
> ⑤ **地图静态数据**：几何精度达上述判据，要素一致率 100%，差异 100% 归因闭环，抽检未发现评测器漏检；
> ⑥ **评审**：未触发暂停退出条件（碰撞、≥ 1 次安全接管、算法节点 core、路线与地图偏差、≥ 2 个高优先级问题），DMG 评审为绿。
>
> 任一项不满足即**不通过**；返工粒度为失败项（单个端点、单个要素点段、单个功能项），不重跑全程；复验通过后重新判定。
