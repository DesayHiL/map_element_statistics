单条路线交付验收：流程与排班

依据《川行无人车智驾验收测试标准》 v6.1 · 2026-10-10 单条路线来回 > 20 次

一、验收流程

门式流程：上一道门通过后才能进入下一道；任一道不通过，就地返修后重验，不进入下一阶段。前三道门的放行判据取自《川行》原文，不由本标准自定。

1.1 各阶段做什么、按什么放行

阶段做什么放行判据出处
G1
HIL 逻辑测试		 真实域控上台架，实时仿真注入场景；功能逻辑与状态机、MRM、失效接管、交通合规、上下电压力、故障降级、标定、远遥 冒烟执行率 / 通过率 100%；无 P0 安全缺陷、P1 清零；基础状态逻辑问题 0；远遥控制权切换类用例 0 失败 W1

二、排班

2.1 为什么这么排

排班不是凑时间，是把上位标准写死的配额落到具体时段。总量、分布、下限都是《川行》明文，排班人无权自定。

序约束上位标准要求出处
①总量单条路线来回 > 20 次W1 · 2.1
②高峰早 / 午 / 晚高峰各至少 2 次W1 · 2.2.1
③时段比例其余时段按 3 : 3 : 4；上、下午各 ≥ 1 次，夜间 ≥ 2 次W1 · 2.2.1
④固定运营客户有固定发车时间时，以客户发车时间为主，不低于 50 km 或 3 次W1 · 2.2.2
⑤时段划分昼夜按当地日出日落划分；同一自然日累计覆盖 td1 / td2 / tn1 / tn2GB/T 44719-2024 · 4.4
⑥里程与载荷单条路线实车测试不少于 200 km，含空载与满载；关键场景需反复验证W1 · 验收体系 1.4
从约束到「21 个来回、各时段几个」的推导（约束是原文，分配是算出来的，可复核）：
① 高峰：早 / 午 / 晚各 ≥ 2 次 —— 早、晚通勤流更强各上浮 1，即早 3 / 午 2 / 晚 3，共 8 个；
② 其余时段按 3 : 3 : 4 分给上午 / 下午 / 夜间：剩余 21 − 8 = 13 个，13 × 3/10 ≈ 4（上午）、13 × 3/10 ≈ 4（下午）、13 × 4/10 ≈ 5（夜间）；
③ 校验：3 + 4 + 2 + 4 + 3 + 5 = 21 ✓；高峰各 ≥ 2 ✓；上下午各 ≥ 1 ✓；夜间 ≥ 2 ✓；其余 4 : 4 : 5 ≈ 3 : 3 : 4 ✓；
④ 短路线追加规则：若 21 × 2 × 单程里程 < 200 km（即单程 < 4.8 km），来回数上调至累计里程 ≥ 200 km 为止（约束 ⑥）。

2.2 排班总表（无固定运营时间 · 默认配置）

取 21 个来回（满足 > 20 次）分摊：三个高峰各 ≥ 2，夜间 ≥ 2，其余按 3 : 3 : 4 分给上午 / 下午 / 夜间。

序时段时间窗口来回单程遍这么排的依据本班次测试内容对应验收指标
1早高峰07:00–09:0036 高峰各 ≥ 2 次，取 3 覆盖通勤高峰段 拥堵跟车与起步、行人 / 非机动车混入、路口多相位信号 DDT 合规 REQ-R-008
2上午平峰09:30–11:3048 3 : 3 : 4 中上午份额；兼满足「上午 ≥ 1 次」 基准采集：光照与交通最稳，作为评测器比对主数据集 地图静态数据全项 §2.4
3午高峰11:30–13:3024 高峰各 ≥ 2 次（取下限） 路口通行、车辆停走、短时变密车流 DDT 合规 + 后援 REQ-R-008/010
4下午平峰14:00–16:3048 3 : 3 : 4 中下午份额；兼满足「下午 ≥ 1 次」 与序 2 作同向重复性校验（版本不变、两次独立采集） 可靠性 §2.4
5晚高峰17:00–19:3036 高峰各 ≥ 2 次；跨越日落，兼顾白天与夜间低照 逆光、大型车遮挡、拥堵跟车、路口饱和流 DDT 合规 + 地图 REQ-R-008

合计——2142 满足总量 > 20、高峰各 ≥ 2、夜间 ≥ 2、上下午各 ≥ 1、其余 3 : 3 : 4 td1 / td2 / tn1 / tn2 时段组合全覆盖 通过标准 §2.4

执行顺序：序 1 + 2 同日连做（早 → 上午）；序 3 + 4 同日连做（午 → 下午）；序 5 + 6 同日连做（晚 → 夜间）。每个来回先去程后返程，同一辆车、同一批人，中途不换车。

载荷与专项（落在来回维度，不额外占时段）：① 空载 / 满载交替安排（如奇数来回空载、偶数来回满载），保证 200 km 内两种工况均覆盖；② AEB 误触发观察每遍进行；③ 端点、复杂路口、施工段等关键场景须在多个时段反复出现并验证结论一致；④ 泛化场景（cut-in、异形车、临时障碍等）随真实交通流自然出现，逐次记录归因。

2.3.3 离线评测（评测器）

把每一遍采回的 ROS bag 交给评测器离线回放：把感知到的静态要素与宽凳高精真值逐项空间匹配、逐项比对属性（STOPLINE / DIVIDER / LANE / ROAD_LINK）——全量比对，不抽样。输出分两路：

  • 差异项 —— 逐条人工校核，判真差异或误检。真差异按三种去向处置，没有「放过」：地图错 → 修图并复验（阻断项）；感知错 → 转问题单跟踪闭环；误检 → 剔除并记录（评测器规则优化线索）。
  • 一致项 —— 从评测器判为「一致」的要素中按里程分层抽样复核。这一步补的是评测器的漏报：只校核差异项只能发现误报，发现不了漏报；若抽检发现漏检，评测器结论不可采信，转全量人工复核。抽检不产生任何容忍额度。

2.3.4 有效遍的条件

每一遍须同时满足下列条件，才计为 有效遍；否则该遍作废、就地补采：

  • ✓ 全程按规划路径行驶，无路段绕行或跳过
  • ✓ 无安全接管、无非策略性干预
  • ✓ ROS bag 完整（静态要素、定位 / 组合导航、时间同步）
  • ✓ 定位全程有效，无丢失或大幅跳变
  • ✓ 起终点及全部途经点按规范停留并完成记录

2.4.2 通过标准（可移交运营）

单条路线验收通过 ＝ 同时满足下列六项：
① 前置门全部放行：G1 / G2 / G3 的放行判据均已满足并取得对应报告；
② 采集完成：完成 ≥ 21 个来回（> 20 次）且累计实车里程 ≥ 200 km（含空载与满载）；td1 / td2 / tn1 / tn2 时段组合覆盖，每遍均为有效遍；
③ 端点与途经点：起点、终点及全部途经点逐个确认合格，零缺陷；
④ 道路表现：无责任事故、无非策略性干预、无不合规（越停止线 / 超速 / 骑轧车道线 / 违规占道）、AEB 无误触发；关键场景反复验证结论一致；事件 100% 记录并归因；
⑤ 地图静态数据：几何精度达 §2.4.1 判据，要素一致率 100%，差异 100% 归因闭环，抽检未发现评测器漏检；
⑥ 评审：未触发暂停退出条件（碰撞、≥ 1 次安全接管、算法节点 core、路线与地图偏差、≥ 2 个高优先级问题），DMG 评审为绿。
任一项不满足即不通过；返工粒度为失败项（单个端点、单个要素点段、单个功能项），不重跑全程；复验通过后重新判定。
