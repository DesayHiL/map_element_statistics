# 高德交通事件接口（et-api.amap.com/event/queryByAdcode）商务申请要点

> 背景：2026-11-07 实测该接口存在但返回 `INSUFFICIENT_PRIVILEGES (10012)`，属高德"商业化接口"，官方文档明确"需通过工单进行商务咨询"。本文件整理申请所需的材料清单与话术要点，供对接高德商务的同事使用。

## 一、目标接口（已技术验证）

| 项 | 内容 |
|---|---|
| 接口 | `https://et-api.amap.com/event/queryByAdcode` |
| 返回 | 交通事件 JSON：事故 / 施工 / 交通管制，含位置与时间 |
| 覆盖 | 全国 360 城市，2 分钟更新 |
| 我们要的 adcode | `441300`（惠州市）/ `441302`（惠城区） |
| 附加 | 配套 `eventpublish/add`（反向发布，不需要） |
| 实测证据 | 2026-11-07 普通 Web 服务 key 调用返回 `{"errcode":10012,"errmsg":"INSUFFICIENT_PRIVILEGES"}` —— 接口在，只差权限 |

## 二、申请三步流程

1. 高德开放平台（lbs.amap.com）注册 + 企业认证（已有 Web 服务 key，此步可跳过）
2. 控制台提交工单 → 商务咨询（或直接联系高德客户经理，车企供应链一般有现成对接人）
3. 审核通过后开通授权，按新文档鉴权

### 使用场景说明话术要点（提高通过率）

- 用途：**自动驾驶 ODD（设计运行域）研究**——道路测试场景风险评估，非对外产品
- 调用方：公司内部研发工具（路测排班/场景覆盖分析），**不对外分发、不转售、不嵌入商业产品**
- 建议走「**非商业研究用途**」通道争取免费权限（高德对非商业用途有免费可能，需人工审核书面说明）
- 若高德不认可"内部工具"属非商业 → 退到正式商务合作（见费用）

### 调用量估算（如实填报）

- 覆盖目标：惠州市 441300 单 adcode
- 采样频率：路测排班周期性刷新，1 次/10 分钟 × 惠州 1 个 adcode ≈ **144 次/日、约 4,320 次/月**（远低于任何档位下限，谈判时可压价）

## 四、费用（公开渠道无独立报价，以下为框架）

| 项 | 金额 | 说明 |
|---|---|---|
| 高德通用技术服务许可费（2025-05 起） | 基础版 5 万/年 · 高级版 10 万/年 | 商业 API 入门票 |
| 交通事件接口 | **另行约定**：按授权城市/区域 + 包年计价，无公开单价 | 单城市（惠州）预计最低档 |
| 百度慧眼对照 | 企业认证 3000 元/年（含 200 万次/日基础额度），事件数据另谈 | 成本低一个数量级，可作谈判筹码 |

**省钱策略：**
1. 先以「非商业研究」申请免费权限 —— 零成本试水，被拒再谈钱
2. 单城市 + 低调用量是压价理由（我们不是全国导航产品）
3. 同时向百度慧眼询价，用竞品报价压高德

## 五、能批下来吗（判断）

- 个人开发者：**基本不可行**（商业接口要求企业主体）
- 德赛西威（车企供应商）以公司名义：**可行**。高德筛选逻辑偏好"车载前装/政府项目/智慧交通"方向，我们是车企 Tier1 的自动驾驶研发，属于高优先客群；但项目是内部研究工具，建议挂靠公司已有的高德商务对接关系（若车机地图用的是高德，走同一条客户经理线最顺）
- 审核周期：企业认证 1-2 个工作日；商务谈判周期取决于客户经理
